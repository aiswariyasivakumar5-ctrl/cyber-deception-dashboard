# Cyber Deception Dashboard 🛡️

An AI-driven cyber deception system that proactively defends networks by deploying intelligent decoys (honeypots) and visualizing attacker behavior through an interactive dashboard.

## 🔍 Project Overview
This project simulates a proactive cybersecurity defense mechanism where decoy server nodes are used to lure attackers. Metrics collected from attacker interactions are visualized using a dashboard to help security analysts understand attack patterns.

## 🧠 Core Technologies
- Python
- Reinforcement Learning (conceptual)
- Streamlit (Dashboard)
- Matplotlib
- JSON-based metrics logging

## 📊 Features
- Attack interaction metrics collection
- Visualization of attacker behavior
- Simple dashboard for analysis
- Modular and extensible design

## 🚀 Use Cases
- Cybersecurity research
- Academic projects
- Internship & portfolio demonstration
- Patent-oriented AI security systems
